# Code of conduct

## The short version

This is a security tool. People bring it bugs, and a bug report here often
means "your tool told me my code was fine and it wasn't". That is the most
valuable thing anyone can hand this project, and it should be easy to do.

So: be straight with each other. Argue with the code, the claim or the
evidence — not with the person holding it.

## What that means in practice

Welcome here:

- Saying a rule is wrong, and showing the file that proves it.
- Saying you don't know.
- Disagreeing with a maintainer's decision in public, with a reason.
- Reporting that the tool missed something you shipped to production.

Not welcome here:

- Harassment, insults, or personal attacks, in issues, pull requests or
  anywhere else this project is discussed.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information.
- Deliberately wasting a maintainer's or contributor's time.
- Dismissing a report because of who filed it rather than what it says.

## Scope

This applies in every space this project uses — issues, pull requests,
discussions and releases — and when someone is representing the project
elsewhere.

## Enforcement

Report it to the maintainer at
`robin@axiomgate.org`, or through GitHub's own
reporting if the maintainer is the problem. Reports are handled privately, and
you'll get a reply within 72 hours.

The maintainer may warn, remove a contribution, or block an account. What
happened is not published; that a decision was made may be.
